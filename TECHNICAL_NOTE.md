# Technical note

IncidentLens uses LangGraph to coordinate an Orchestrator, Observability and Dependency specialists, Reasoning, Critic and Reporting. A task DAG permits independent queries to run concurrently and blocks dependants until prerequisites complete. Structured results join into shared evidence by stable ID. Critic questions drive conditional replanning and new tool queries, with repeat-query and no-progress checks.

A shared LangChain runner supplies native Gemini tool calls, role-specific access and Zod results. Gathering and structured output use separate requests; native message identifiers and thought signatures survive tool round-trips. Logs and history are untrusted data. Held-out evaluation labels and injected failure schedules never enter agent prompts. There are no per-case answer lookups.

Tool envelopes distinguish empty, partial and unavailable sources. Retryable source failures receive one retry. Model requests allow three total attempts, including at most one output repair. Monotonic deadlines, round/call/token budgets, concurrent input reservations, cancellation and reporting reserves bound execution. Live tests exposed oversized schema reservations, inadequate reporting capacity, tool-argument mistakes and empty citation arrays; admission estimates, reserves and native schemas now match the actual request contract.

Reporting preserves the assessed hypotheses, confidence and contradictions in the host. Native output is restricted to inconclusive when corroboration is insufficient or critic questions remain unresolved. This prevents a single-record assessment from becoming a reporting failure. Facts and actions require retrieved references; semantic grounding is evaluated separately. Unrecovered failures yield an explicit inconclusive fallback.

The general-investigator baseline shares tools, settings, budgets and accounting. The latest complete ten-case comparison achieved 19/20 successful executions: multi-agent root-cause accuracy 5/9 versus baseline 8/9, with grounding macro scores 90.7% versus 71.3%. The remaining execution exhausted retries on provider 503. This comparison precedes final citation/reporting changes. Later focused testing completed 3/4 investigations, and twelve Reporting-only replays passed. A final checker-schema regression was fixed offline after the 480-request cap; its live retry and a full final-revision benchmark remain outstanding. The published comparison retains its failed execution. Redundant development logs are archived locally.

Reported usage is incomplete, so token totals are known subtotals and estimated admission cannot guarantee an exact actual-token ceiling. Ten synthetic incidents and an automated judge do not establish production accuracy. Multi-agent coordination costs more and did not outperform the baseline. Next improvements are broader held-out evaluation, calibrated uncertainty, stronger causal ownership checks, independent grounding review and deployment-level quota coordination. LangGraph runs locally without an account; LangSmith is optional. The dashboard streams actual events and retrieved evidence; it executes no remediation and loses temporary runs on restart.
